  缺失时 `quantify.py` 自动降级为词典正则+字符级，不影响运行。

- 运行：`python code/run_all.py`（依次执行问题1→问题2→问题3→生成报告）。

## 主要结论
- 问题1：4个一级维度、16个二级指标，AHP权重由专家判断矩阵复算（全部 CR<0.1）；
  16个二级指标逐一采用专属量化方法（分节覆盖、闭环检测、断层规则、模型词典、行级公式、符号表、行首章节、重复句检测等，详见报告表1）。
  分级采用相对分位定级（优秀≥P85/良好≥P65/中等≥P40/及格≥P20），29篇自动评分：优秀5篇、良好5篇、中等7篇、及格6篇、不及格6篇（得分55.9~78.4）；
  25.pdf 为纯图片扫描件已标记排除。
- 问题2：12项特征在剔除代码附录页后的正文上计算（内容页数/字符数、行首标题章节、行级公式、逐式编号、引用-条目），
  质量得分60.2~71.4；可量化文本特征与质量得分的关联整体较弱且方向不一（内容页数/字符数弱正相关、连词类弱负相关）；
  预测模型以内容字符数（单特征）为自变量，n=9 下留一交叉验证 R²<0、外推能力不足；质量调整因子 k=1+λ·(F−F̄)/F̄（λ=0.30）基于特征剖面校准基础得分，调整幅度约±2~5分。
- 问题3：3-1/3-2/3-3 基线 59.79/62.56/59.04（均“中等”，与题目预设一致），AI检测采用参考算法五维（句首重复率/句式变化性/段落均匀度/逻辑异常度/术语偏离度，3篇内min-max+附件1参照）；
  针对薄弱指标给出修改方案后预测得分提升至 61.39/64.43/61.82。
